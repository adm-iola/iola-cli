# Commands

Основные команды:

```bash
iola --help
iola help
iola commands
iola init
iola doctor
iola doctor --fix
iola update
iola version --check
iola config validate
iola config schema
```

Данные:

```bash
iola search "Петрова"
iola search "Петрова" --local --fts
iola schools --limit 10
iola kindergartens --search "29"
iola card "школа 29"
iola data schools --format csv --output schools.csv
```

Геокодер:

```bash
iola yandex cloud setup
iola yandex cloud status
iola geo key set yandex
iola geo key status
iola geo key doctor
iola geo geocode "Йошкар-Ола, улица Петрова, 15"
iola geo nearby "Йошкар-Ола, улица Петрова, 15" --dataset all --limit 5
iola geo distance --from "Петрова 15" --to "школа 7"
iola geo map-link "школа 7"
iola geo resolve "садик золотой петушок"
iola geo route-context "школа 7"
iola geo services "Йошкар-Ола, улица Петрова, 15"
```

Яндекс Go deeplink:

```bash
iola yandex go status
iola yandex go link --from "Йошкар-Ола, Красноармейская 43" --to "Йошкар-Ола, Гагарина 8"
iola yandex go open --from "Йошкар-Ола, Красноармейская 43" --to "Йошкар-Ола, Гагарина 8" --tariff econom
```
