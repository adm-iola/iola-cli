# iola-cli

`iola-cli` - CLI и AI-агент городского округа "Город Йошкар-Ола".

Основные сценарии:

- поиск школ и детских садов;
- просмотр карточек организаций;
- локальная синхронизация данных в SQLite;
- проверка качества данных;
- выгрузка CSV/JSON;
- работа с локальной моделью Ollama;
- работа с YandexGPT, GigaChat, OpenAI, OpenRouter и Codex CLI;
- geo-сценарии для жителей через Yandex Geocoder API;
- Yandex Connector для пользовательских сервисов Яндекса;
- Yandex Cloud Connector для геокодера, YandexGPT и deeplink Яндекс Go;
- личные облачные диски: Яндекс Диск и Облако Mail.ru;
- подключение публичного MCP-сервера.

Быстрый старт:

```bash
npm install -g @iola_adm/iola-cli
iola init
iola search "Петрова"
iola ask "найди школу 29"
```
