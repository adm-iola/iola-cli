Используй этот skill, когда пользователь явно просит работать с домофоном Дом.ру: подключить сервис, показать адреса, показать домофоны, открыть дверь, посмотреть историю событий или получить временные коды.

Если пользователь говорит просто `открой домофон` или `покажи домофоны` без названия провайдера, это общий сценарий "Мой домофон": CLI должен проверить все подключенные провайдеры и выбрать домофон по адресу, а не требовать слова "Дом.ру".

Не смешивай Дом.ру с Уфанетом, Ростелекомом, городскими открытыми слоями и локальными файлами. Это отдельный личный сервис пользователя.

Доступные tools:

- `domru_status` - проверить, подключен ли Дом.ру.
- `domru_places` - показать адреса пользователя.
- `domru_intercoms` - показать доступные домофоны.
- `domru_open_intercom` - открыть домофон по ID; если ID не указан, CLI сам получает список домофонов.
- `domru_call_history` - показать историю событий.
- `domru_temporal_codes` - показать временные коды домофонов.

Команды CLI:

- `iola dom_ru setup` - подключить Дом.ру.
- `iola dom_ru status` - проверить подключение.
- `iola dom_ru places` - список адресов.
- `iola dom_ru intercoms` - список домофонов.
- `iola dom_ru open ID` - открыть домофон после подтверждения.
- `iola dom_ru open` - если домофон один, открыть его; если несколько, попросить выбрать цифрой.
- `iola dom_ru history` - история событий.
- `iola dom_ru codes` - временные коды.
- `iola dom_ru delete` - удалить локальное подключение.

Безопасность:

- Для `domru_open_intercom` всегда нужен явный запрос пользователя и `confirm=true`.
- Если пользователь просит "открой домофон Дом.ру", а ID не указан, CLI должен сам получить список домофонов. Если домофон один - открыть его. Если домофонов несколько - показать адреса с цифрами и ждать выбор цифрой; выбранная цифра считается подтверждением.
- Не открывай домофон по косвенному намерению вроде "кто там", "звонят", "посмотри".
- Не выводи логин, пароль, access token, refresh token и другие секреты.
- Если Дом.ру не подключен, скажи запустить `/master` и выбрать `Мой домофон Дом.ру`, либо команду `iola dom_ru setup`.

Ростелеком:

- `/rostelecom` пока является заготовкой "в разработке".
- Не обещай работу Ростелекома, пока его API не реализован.
